REFRACT / A REAL-TIME VISUAL PLAYGROUND手势 × 蒙版 × 你的视角
QUICK START

把双手，变成创作工具。

  1. 开启摄像头允许浏览器使用摄像头；模型首次初始化需要几秒钟。
  2. 叠加特效点击特效卡片添加蒙版。每层都能独立调整透明度、形状和混合方式。
  3. 捏合，移动拇指和食指捏合，抓住指尖处的蒙版。松开即可放下。
  4. 双手，缩放先选中图层，再用双手同时捏合；拉开双手放大，靠近缩小。
  5. V 手势，拍照仅伸出食指和中指，保持约 1 秒。放下手后可再次触发。
  6. 保存作品点击拍照或录制；停止录制后从作品区下载。录像不包含声音，也不包含辅助线。

鼠标 / 触屏：拖动蒙版或右下角。键盘：空格拍照、R 开始 / 停止录像、Delete 删除当前图层。摄像头只能在 HTTPS 或 localhost 页面中使用。演示模式也能拍照和录像。

摄像头与手势计算仅在当前浏览器内进行。作品暂存于本次会话，刷新或关闭页面前请下载。录像每段最多 3 分钟；后台切换时会自动结束。
